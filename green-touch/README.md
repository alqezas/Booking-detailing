# Green Touch

Інтернет-магазин косметики власного виробництва (усе під замовлення): каталог із комбінованими фільтрами, набори зі знижкою −15 %, кошик, оформлення з вибором відділення/поштомату Нової пошти, повна оплата через plata by mono (картка, Apple Pay, Google Pay) або передоплата 150 грн через Viber з накладеним платежем, захищена адмінка, PWA.
