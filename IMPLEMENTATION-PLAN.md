## Решения (кратко)

- **Bottom sheet:** вместо shadcn Drawer используется `BottomSheetSwitcher` из Astryx — одна шторка
  на весь сценарий без второй дизайн-системы и без Tailwind (в проекте нет Tailwind-компилятора,
  AGENTS.md запрещает утилитарные классы). Смысл требования — «последовательная шторка, одна ветка
  компонента» — сохранён.
- **Тема:** собирается во время работы из `defineTheme(extends: neutral)`, потому что акцент хранится в БД
  и меняется владельцем. Из одного цвета выводятся заливка кнопок (≥ 4.5:1 с белым) и цвет акцентного
  текста (≥ 4.5:1 на чёрном) — `shared/color.ts`.
- **Хостинг:** Vercel (по третьему промпту); сборка полностью статическая и подойдёт и для Cloudflare Pages.
  Деплой — `vercel build` + `vercel deploy --prebuilt`.
- **Стекло:** у liquid-gl цель стекла становится неинтерактивной, поэтому стекло — отдельный декоративный слой
  под настоящей кнопкой. Снимок для кнопки на фото берётся только с элемента фотографии — буквы соседних
  разделов в линзу попасть не могут; надпись — обычный DOM поверх линзы.
- **Фото:** фото из `business.json` раздаются сайтом (`/s/<slug>/media/…`); загрузки владельца — в бакет
  `tenant-media/<tenant_id>/…`, писать туда может только участник студии.
- **Токен клиента:** детерминированный HMAC(booking, idempotency key) — повтор того же запроса возвращает тот же
  токен, а в БД лежит только SHA-256.
- **Многодневные услуги:** бокс занят непрерывно на `длительность + подготовка`, включая ночи; часы работы
  ограничивают только момент приёма (короткие услуги ещё и должны закончиться до закрытия).
- **IP для лимитов** берётся из заголовков прокси; дополнительно стоят лимиты на телефон и на студию,
  которые подделкой заголовков не обойти.
- **Пароли владельцев** создаются конвейером и пишутся в `.secrets/owners.local.txt` (git-ignored), не в консоль.
